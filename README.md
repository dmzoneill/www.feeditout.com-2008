# feeditout.com (2008)

The 2008 version of the Feed It Out site.

## Contents

PHP pages for login and access control, contact and mail, books, texts, serials,
music, video, samples and training material, a CAPTCHA, an nmap frontend and
webalizer statistics.

## Tech

- PHP and MySQL
- JavaScript

This is an archive of an old site, kept for reference.
